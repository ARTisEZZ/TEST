# Взрыв-схема бортовой 4-лучевой АФАР S-диапазона (Direct-to-Cell)

Техническая инфографика 16:9 для печати на A3: слои системы разнесены вдоль одной оси,
от антенного полотна к спутниковой платформе.

| Файл | Что это |
|---|---|
| `afar_exploded_view.png` | Готовое изображение 4992×2808 px (≈300 dpi при ширине A3) |
| `afar_exploded_view.svg` | Векторный оригинал 1920×1080, масштабируется без потерь |
| `generate.py` | Генератор SVG: элементы заданы в 3D и спроецированы видом слева-спереди |
| `render.js` | Рендер SVG → PNG через Chromium (Playwright) |
| `prompt.md` | Исходный промт для генеративной модели (фотореалистичный вариант) |

## Пересборка

```bash
python3 generate.py          # -> afar_exploded_view.svg  (нужен Pillow и шрифт Inter)
node render.js               # -> afar_exploded_view.png  (масштаб 2.6 по умолчанию)
node render.js 4 big.png     # другой масштаб/имя файла
```

Тексты выносок, параметры панели и легенда лежат в `generate.py`
(списки `CALLOUTS`, `PARAMS`, `LEGEND`, `CHEVRONS`), цвета соединений — в константах
`TX`, `RX`, `PW`, `CT`, `GR`.

## Правка SVG в редакторе

`afar_exploded_view.svg` открывается в Inkscape, Illustrator, Figma, Affinity Designer.

- Рисунок разложен по именованным слоям (в Inkscape — панель «Слои и объекты»):
  «Фон», «Заголовок», «1 — Антенное полотно» … «10 — Спутниковая платформа»,
  группы соединений («Соединения: …»), «Выноски 1–10», «Панель параметров»,
  «Цветовая легенда», «Лента шевронов».
- Каждая выноска — отдельная группа «Выноска N — …» с подгруппами
  «плашка», «текст», «линия-лидер»; все подписи — живой текст.
- Перенос строк в выносках сделан отдельными текстовыми строками: при правке
  текста строки переносятся вручную (или правьте `CALLOUTS` в `generate.py`
  и пересоберите — перенос посчитается автоматически).
- Шрифт — **Inter** (бесплатный, Google Fonts). Без него редактор подставит
  DejaVu Sans/Arial и ширина строк немного изменится.
- Тени объектов и свечение рамки подрешётки сделаны SVG-фильтрами: в Inkscape и
  браузерах они видны, в редакторах без поддержки фильтров просто пропадут.

## Цветовое кодирование

красный — TX, синий — RX, зелёный — питание, жёлтый — управление и данные
(LVDS, M-LVDS, CAN, SPI, PPS, LOAD), серый — конструктив, фильтры, разъёмы.
Стрелки показывают направление потока.

## Отличия от промта

Изображение нарисовано программно в векторе (градиенты, тени, псевдо-3D), а не
фотореалистичным 3D-рендером. Композиция, нумерация 1–10, тексты выносок,
панель параметров, легенда и нижняя лента шевронов соответствуют `prompt.md`.
Для фотореалистичной версии промт можно отдать генеративной модели
(Midjourney, DALL·E и т. п.) — эта схема пригодится как референс компоновки.
